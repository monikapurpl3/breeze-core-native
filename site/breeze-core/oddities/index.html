Breeze Core, on everything else

The same 4.3.2, cross-compiled for sixteen more systems, for the fun of seeing how far one small Rust program goes. Some are plausible homes for an air-conditioner controller. Some are a watch.

None of these has ever run. There is no machine for any of them here, so each was checked only as a file: its format, its loader, the libraries it asks for. They are frozen at 4.3.2 and will not be rebuilt for later releases. For anything that matters, use a supported build, which covers 22 systems and is run before it ships. If you do start one of these, a report either way is very welcome.

How they were made

All on one Windows workstation, from the 4.3.2 source unchanged. Where zig carries a system's C library (FreeBSD, NetBSD, Linux) it links; where it does not, the system's own libraries were downloaded and checked against their published checksums — OpenBSD's and NetBSD's release sets, illumos's and Solaris's sysroots, DragonFly's install image, Haiku's packages — and clang and lld linked against them. watchOS got a hand-written stub of the two system libraries it calls. The tier 3 targets had Rust's standard library built from source.

Each binary reports breeze-core 4.3.2 commit 2ef0d09, the commit 4.3.2 was released from.
