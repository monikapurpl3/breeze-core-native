Breeze

The Android app for Breeze Core: one air conditioner per screen, home-screen widgets, and schedules that run on the server, over your own network. No cloud account, and two permissions: internet and vibrate.

Breeze-@APP_VER@.apk (@APP_MB@ MB · sha256) · Android 7.0 or newer.

A file to download rather than a package to install by name: Android has no repository to add, and there is no Play listing. The phone asks once to allow installs from your browser or file manager. Every release is signed with the same key, so a new one installs over the old one and keeps your servers and pairing.

Installing

On the phone: download it and open it. Or from a computer, over USB: 
# check the download, then install it with USB debugging on
sha256sum -c Breeze-@APP_VER@.apk.sha256
adb install -r Breeze-@APP_VER@.apk

It needs a server. Breeze is the client; Breeze Core runs on your network and does the talking to the air conditioners. On first launch the app asks for the server's address, its access key and a name for this phone. Then it shows a one-time code, and an administrator approves it on the local network with breeze-core approve <code>. Each phone gets its own credential, which can be revoked on its own.

The signing certificate's SHA-256 is e4ab9cb5 c737530b 74a1aabe a04707f2 519a5ee1 fd1d1106 55e1e898 96d6949f. apksigner verify --print-certs shows it for the file you have.

What you get

the control screenone unit per screen, tinted to its mode, changes shown at once and pushed live by the server
without opening ithome-screen widgets for power and temperature
programsfavourites, weekly schedules and temperature curves, run by the server, so they fire with the phone off
timersoff after a while, or on at a set day and time
accessibilityTalkBack, Switch Access, Voice Access and large text: every control is named and says how it is set
more than one homeseveral servers, each paired once
when it misbehavesa diagnostics screen that checks the server, the pairing and every unit

The app and the server version separately. It works with any Breeze Core and uses whatever that server offers.
